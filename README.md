## 🛠️ O que eu construo

- **Agentes de IA em produção** — orquestração com LangChain e LangGraph, com persistência de estado para operação distribuída
- **Agentes de voz** — pipeline de STT, LLM e TTS com LiveKit Agents, em projeto de discagem outbound multi-tenant
- **Engenharia de prompt em escala** — geração dinâmica de system prompts por cliente, com formato independente de fornecedor (OpenAI, Anthropic, Gemini)
- **Integração de IA com sistemas corporativos** — CRM, marketplaces, agendamento e canais de mensageria, com OAuth e credenciais isoladas por tenant
- **Segurança e governança de IA** — isolamento de segredos, proteção contra SSRF, controle de custo por modelo e fallback entre provedores

## 📈 Estudando agora
